# Labelling guideline (grades A–F)

Each crop shows one building and gets one grade. The grades describe what can be seen of the building's state. They are adapted from the INSARAG worksite triage categories, but they don't use victim information. The scale is ordinal: A = 0 … F = 5.

| Grade | Definition |
|---|---|
| A | Intact building |
| B | Intact building with broken windows or similar minor damage |
| C | Standing building with damage (visible cracks, damaged walls) |
| D | Collapsed building with voids; parts of the structure still stand and it is recognisable as a building |
| E | Pancake collapse: stacked floor layers |
| F | Debris |

## Borderline cases

| Situation in the crop | Grade |
|---|---|
| View from inside an intact room | C |
| View from inside a partially collapsed room that still exists | D |
| Mostly pancake layers, but with a void a person could fit in | D (the possible void decides) |
| Rescuers inside a cramped void, nothing else of the building visible | D |
| Too small, dark, blurred or covered to grade (no building, or the building can't be seen) | exclude |

Crops with a short side under 96 px were removed before labelling. In a blind re-labelling of the test set they were mostly marked "exclude".
